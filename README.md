# Unsupervised-Keypoints-for-Real-Time-Fall-Detection
1. yolo_segmentation_files folder is used to segment persons from video frames.
2. After that, segmented videos needs to be converted in .npz format.
3. Then, the folder name with .npz files needs to be defined in hyperparameters.py and finally, train.py is used to train the model and get inference results.
